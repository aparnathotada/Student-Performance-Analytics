
# Student Performance Analytics System

## 1. Introduction
The Student Performance Analytics System is a Python-based project
that analyzes student marks and attendance to understand academic
performance.

## 2. Technologies Used
- Python
- NumPy
- Pandas
- Google Colab

## 3. Features
- Stores student details and marks
- Calculates total and average marks
- Assigns grades to students
- Identifies PASS or FAIL results
- Calculates class average
- Finds highest and lowest performers
- Performs subject-wise analysis
- Displays the top 3 performers
- Generates a final student report
- Saves results in a CSV file

## 4. Dataset
The project uses 15 student records containing:
Student ID, Name, Department, Python marks, SQL marks,
Statistics marks, and Attendance.

## 5. How to Run
1. Install Python, NumPy, and Pandas.
2. Keep main.py and students.csv in the same folder.
3. Run the command: python main.py

## 6. Conclusion
This project demonstrates how Python, NumPy, and Pandas
can be used to analyze student academic performance
and generate useful reports.
